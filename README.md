#3⚔️ Vinland Saga - Web Project

Projeto web inspirado no universo do anime/mangá Vinland Saga, desenvolvido para o Curso Técnico em Informática.

📌 Sobre o Projeto

Este projeto consiste na criação de um site temático sobre a obra Vinland Saga. O objetivo principal é demonstrar na prática os conhecimentos adquiridos durante as disciplinas do Curso Técnico em Informática, incluindo desenvolvimento front-end, estruturação de páginas, estilização responsiva e manipulação de scripts no navegador.

O site apresenta os principais aspectos da obra, como a jornada de Thorfinn, a introdução aos personagens marcantes (Askeladd, Thorkell, Canute) e o contexto histórico da era viking.

🚀 Funcionalidades

📖 História & Lore: Apresentação da sinopse e arcos principais da série.

🛡️ Guia de Personagens: Cards interativos detalhando os principais personagens.

🎨 Interface Temática: Design visual personalizado com cores e elementos do universo da obra.

📱 Layout Responsivo: Adaptação completa para dispositivos móveis, tablets e desktops.

✉️ Formulário de Contato / Feedback: Seção interativa para interação dos usuários.

🛠️ Tecnologias Utilizadas

As principais tecnologias e ferramentas aplicadas no projeto foram:

HTML5: Estruturação semântica do conteúdo.

CSS3: Estilização, animações, Flexbox/Grid e responsividade.

JavaScript: Interatividade, controle de elementos na tela e lógica front-end.

Git & GitHub: Controle de versão e hospedagem do código-fonte.
