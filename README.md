## 🎯 Sobre o Projeto
O objetivo principal deste projeto foi aplicar os conhecimentos fundamentais de desenvolvimento web aprendidos ao longo do curso técnico (HTML5, CSS3 e JavaScript), focando na criação de uma interface temática imersiva, design responsivo e boa experiência do usuário (UX/UI). 

O site funciona como uma página temática (landing page / portal de fãs) apresentando a história, os principais personagens da saga viking (como Thorfinn, Askeladd e Canute), arcos narrativos e uma galeria de imagens inspiradas na obra de Makoto Yukimura.

---

## ✨ Funcionalidades
- **Design Imersivo:** Estética visual inspirada no universo medieval/viking, com paleta de cores sóbria, tipografia temática e efeitos visuais.
- **Responsividade:** Layout adaptável para diferentes tamanhos de tela (computadores, tablets e smartphones).
- **Navegação Dinâmica:** Menu interativo e seções bem estruturadas (História, Personagens, Arcos e Contato).
- **Componentes Interativos:** Cards de personagens com descrições detalhadas, carrossel de imagens/cenas marcantes e formulário de contato/newsletter funcional.

---

## 🛠 Tecnologias Utilizadas
As seguintes tecnologias e ferramentas foram empregadas no desenvolvimento do projeto:

- **HTML5:** Estruturação semântica das páginas.
- **CSS3:** Estilização, Flexbox, Grid Layout, animações e variáveis CSS.
- **JavaScript (ES6+):** Linter de interatividade, manipulação do DOM e comportamentos dinâmicos.
- **Git & GitHub:** Controle de versão e hospedagem do repositório.
- **VS Code:** Ambiente de desenvolvimento integrado (IDE).
